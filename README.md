# WordPress建站教程：从选主机到装宝塔，新手用免备案节点把站点跑起来

搜这个词的人，多半已经知道 WordPress 是什么，也点过一遍安装向导。真正卡住的地方在前面：买什么样的机器、要不要备案、PHP 选哪个版本、域名解析完了为什么还是打不开。

这篇就按这个顺序讲。主机部分拿雨云举例，因为它把宝塔面板做成了开箱可用的形态，价格也压在两位数区间，适合第一次建站的人拿来跑通流程。价格数据来自公开资料与官方文档整理，各区域、各机型差异不小，下单前请以购买页的实时标价为准。

## 一、先算清楚机器要多大的，再谈安装

WordPress 的性能瓶颈几乎不会出现在 CPU 上，而在内存。PHP-FPM 进程、MySQL 查询缓存、缓存插件、后台任务，全都在抢内存。2GB 内存装上十几个插件就会开始吃紧，表现为后台卡顿、进程频繁重启。所以别一上来就纠结几核，先看内存。

| 站点类型 | 日访问量参考 | 建议配置 |
| --- | --- | --- |
| 个人博客、企业展示站 | 千次以内 | 2 核 2G，40G 硬盘 |
| 更新频繁的资讯站 | 数千次 | 2 核 4G，60G 以上 |
| 带商品和会员的电商站 | 上万次 | 4 核 8G 起，考虑独立数据库 |

带宽不用堆。图文站 3～5Mbps 能覆盖大部分场景，图片多的站把静态资源交给对象存储和 CDN，比单纯加带宽便宜得多。硬盘同理，先买小的，需要时扩容——雨云的云盘扩容是 SSD 云盘 0.4 元/GB/月、高效云盘 0.1 元/GB/月，按需加比一次买大更划算。

## 二、虚拟主机、云服务器，到底选哪个

三种主流选择，差别不在价格，在你愿意接手多少运维工作。

**虚拟主机**：环境是现成的，进去就有面板，价格低，但资源是共享的，能改的东西有限。适合个人博客、企业展示站这类需求固定的站点。

**云服务器**：给你一台完整的机器和 root 权限，装什么环境自己定，配置能随时升，代价是系统补丁、安全组、性能排查都得自己管。

**托管 WordPress 主机**：省心，但费用通常高出好几倍，中小站点不太划算。

雨云这两类产品都在卖。云服务器覆盖美国洛杉矶、日本东京、中国香港、深圳、湖北、江苏宿迁、重庆等区域，支持预装宝塔、1Panel 这类面板和常见运行环境。虚拟主机（官方叫 Rain Virtual Host）是专门用来开网站的产品，又分两个面板体系：

- **宝塔主机**：不限网站数量、不限数据库和域名，带完整功能的宝塔面板，支持 SSH/SFTP/MySQL 远程连接，可以附加独立 IP，能跑 PHP、Java、Python 等环境。建站选它就对了。
- **EP 主机**：EasyPanel 面板，很轻量，只支持 PHP + 单个 MySQL 数据库，单台主机限制绑定 5 个域名。适合纯静态页或者单个 PHP 站。

雨云官方文档里写得很直白：建议所有用户选购宝塔主机，无论新手还是老手都能掌握。这话不算营销——EP 主机装 WordPress 能装，但你迟早会碰到"想加个站点发现绑不了域名"的尴尬。

### 免备案还是备案，这一步决定你的上线时间

选美国、香港、日本这类境外节点，域名解析到 IP 就能访问，不用走备案流程。代价是内地访问会有一点延迟，访问者主要在海外的话反而更合适。

选湖北、江苏宿迁、重庆、深圳这类内地节点，必须完成 ICP 备案，通常要等 7～20 个工作日。域名得先实名认证，服务器要选包年包月并且剩余时长满足要求。第一次建站、想当天就看到成果的，建议先用香港或美国节点把流程跑通。

## 四、从付钱到站点能打开，一共七步

1. **选区域和机型**。系统镜像直接选预装宝塔的 Debian 或 Ubuntu 版本，省掉装面板这一步。
2. **拿到访问信息**。云服务器会给公网 IP 和 root 密码；虚拟主机则在雨云管理面板里确认主机状态和面板地址。
3. **装运行环境**。进宝塔面板装 LNMP，PHP 选 8.1 或 8.3，MySQL 选 8.0。现在的 WordPress 生态对 PHP 7.x 基本已经断了兼容，主流插件（Elementor、WooCommerce、Yoast SEO 等）都不再支持，别图省事选老版本。
4. **建站点和数据库**。记下数据库名、用户名和密码，后面安装向导要用。
5. **装 WordPress**。下载官方中文包，解压到站点根目录，访问域名就会进入安装向导，按提示填数据库信息、站点标题和管理员账号。
6. **解析域名**。域名服务商那边加 `@` 和 `www` 两条 A 记录指向服务器 IP，两条都要加，否则带 www 和不带 www 只有一个能通。
7. **上 HTTPS**。面板里申请免费证书，签发后开启强制 HTTPS，再回 WordPress 后台把「WordPress 地址」和「站点地址」都改成 `https://` 开头。这一步不做，页面会样式丢失、图片不显示。

### 装 WordPress 时最容易翻车的一个细节

雨云的宝塔虚拟主机是容器化的，数据库这块有个坑：

> 在网页程序里填数据库地址，一律填 `127.0.0.1`、端口 `3306`。面板上显示的那个远程 MySQL 端口是给 Navicat 之类的外部工具用的，填进 WordPress 的配置文件里会直接连不上。

同一个原因，如果你没附加独立 IP，phpMyAdmin 的访问端口要用雨云面板显示的那个端口，把链接里的 888 替换掉。

### 域名要绑定两次

在宝塔里建站、绑定域名之后，还要回雨云虚拟主机管理面板再绑一次。漏掉这一步，站点在本机测试正常，域名就是打不开——这是虚拟主机用户反馈最多的问题之一。

### 改完固定链接就 404

在站点的伪静态设置里选 WordPress 对应的规则保存即可。别急着改代码。

## 五、站点能打开之后，还有三件事必须补

**备份**：站点目录和数据库要分开备份、一起恢复。只备份其中一个，出事时拿到的都是残缺数据。宝塔主机自带定时备份功能，完成微信绑定的用户还有免费的备份存储额度，超出的部分按量计费。

**安全**：管理员用户名不要用 admin，这是自动化爆破的第一个尝试对象；关掉后台的在线文件编辑功能；限制登录失败次数；核心、主题、插件保持更新。面板管理端口也别对全网开放，只放行自己的办公网络 IP。

**性能**：装一个缓存插件，把动态页面生成静态 HTML，PHP 和数据库压力立刻下降一截；图片上传前压缩；图片和附件多的站，把静态资源交给 CDN 或对象存储分担。雨云本身有对象存储和 CDN 产品，接起来不麻烦。

## 七、几个高频问题

**服务器买了、IP 能 ping 通，域名却打不开？**
九成是 A 记录没生效或指向错了，用 `dig +short 你的域名` 对一下返回的 IP。虚拟主机用户还要确认雨云面板里也绑定了域名。

**后台能进，前台白屏？**
通常是主题或插件报错。把 `wp-content/plugins` 目录临时改名，强制停用全部插件，前台恢复说明问题在插件，再逐个启用定位。

**站点越用越慢，该升什么？**
先用监控看是 CPU、内存还是磁盘 IO 吃紧。内存不足的表现是 PHP 进程反复重启，这种情况下升 CPU 没用。

**能不能自己在宝塔里升级面板版本？**
官方建议不要升级，可能出现预料之外的问题。真把面板弄坏了，用雨云提供的修复主机功能处理，别硬扛。

**共享 IP 会不会有影响？**
建站本身不影响，但如果有 SEO 或邮件送达方面的顾虑，可以附加一个独立 IP，费用按套餐周期计算。
